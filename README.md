# 坦克大战 · Battle City

一个纯 HTML5 Canvas 实现的经典坦克大战（Battle City）游戏。单文件 `index.html`，无需任何依赖，用浏览器打开即可游玩。

## 玩法

| 操作 | 按键 |
| --- | --- |
| 移动 | `W A S D` 或方向键 |
| 射击 | `空格` |
| 暂停 / 继续 | `P` |
| 静音 | `M` |
| 开始 / 重新开始 | `回车` |

保护下方基地 🦅，消灭所有敌人。吃到道具可增强实力：

- `★` 升级火力（更快的射击、双发子弹）
- `🛡` 护盾（短暂无敌）
- `♥` 增加一条生命
- `💣` 消灭当前场上所有敌人

敌人类型：普通坦克、快速坦克、强力坦克（射速快）、装甲坦克（需多次命中）。
